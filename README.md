# 自作ゲーム置き場

自作ブラウザゲームのリンク集。ボタンを押すと小ウィンドウが開いて、解説とゲームへ飛ぶボタンが出る。

## ゲームを増やす手順

1. スクショを `images/` に放り込む（任意）
2. `games.js` を開く
3. 下のカタマリをコピペして、中身を書き換える（**末尾のカンマ `,` を消さないこと**）

```js
  {
    title: "ゲームタイトル",
    url:   "https://ユーザー名.github.io/リポ名/",
    img:   "images/ファイル名.png",
    desc:  "ここに短い解説。"
  },
```

4. コミットして push

```bash
git add -A && git commit -m "add game" && git push
```

## 各項目

| 項目 | 必須 | 説明 |
|---|---|---|
| `title` | ◯ | ボタンに出る文字。モーダルの見出しにも使う |
| `url` | ◯ | ゲームのURL。別タブで開く |
| `img` | – | `images/xxx.png` でも `https://...` でもOK。省略すると絵文字＋単色タイル |
| `desc` | – | モーダルに出る解説。1〜2行推奨 |
| `icon` | – | 画像が無いときの絵文字。省略時は 🎮 |

## 画像について

**ぼかし済みの画像を用意する必要はない。** 素のスクショをそのまま置けばいい。
ボタンの背景はCSS側で自動的にぼかし＋暗転がかかり、文字が前面に来る。
マウスを乗せるとぼかしが外れて画像がクッキリ見える。モーダル内は最初からぼかし無し。

画像のサイズ・縦横比はバラバラでOK。`background-size: cover` で自動的に収まり、
ボタンの形が崩れたりはみ出したりはしない。

ぼかし具合・明るさを変えたいときは `style.css` の冒頭：

```css
--card-blur: 4px;     /* ぼかし量。強くしたいなら増やす */
--card-bright: 1.15;  /* 明るさ。1=そのまま 1未満=暗く 1超=明るく */
```

タイトル文字の可読性はボタン下部の黒いグラデーションが担保しているので、
`--card-bright` は「画像の内容が見えるか」だけを基準に決めていい。
元から暗いゲームのスクショは 1.2〜1.4 くらいまで上げると見えやすくなる。

## ローカルで確認

`index.html` をダブルクリックするだけ。サーバー不要。
